## 📌 Pregunta 1

El archivo `README.md` es fundamental en un proyecto, ya que funciona como una guía inicial para cualquier persona que quiera entender, usar o modificar el código. Según la documentación oficial de GitHub, este archivo suele ser el primero que los usuarios revisan al ingresar a un repositorio.

Su importancia radica en que permite explicar aspectos clave como:
- El propósito del proyecto  
- Cómo instalarlo o ejecutarlo  
- Qué funcionalidades tiene  
- Cómo contribuir  

Para alguien que no participó desde el inicio, el README actúa como una introducción clara y estructurada, evitando que tenga que leer todo el código para entender su funcionamiento. Sin este archivo, el proyecto pierde accesibilidad y se vuelve más difícil de utilizar o mantener.

**Fuentes:**
- https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes
- https://www.codecademy.com/article/markdown-and-readmemd-files

## 📌 Pregunta 2

Un archivo `Makefile` permite automatizar el proceso de compilación y ejecución de un programa, especialmente en proyectos que contienen múltiples archivos. Esta herramienta es ampliamente utilizada en entornos de desarrollo, particularmente en C y C++.

Su utilidad principal es:
- Evitar compilar manualmente cada archivo  
- Reducir errores en el proceso de compilación  
- Estandarizar la construcción del proyecto  

Para otras personas, un Makefile facilita el uso del proyecto, ya que basta ejecutar un comando como `make` para compilar todo correctamente.

Además, puede utilizarse en distintos lenguajes de programación, como:
- C / C++  
- Java  
- Python (para automatizar tareas)  
- Go, Rust, entre otros  

Sin embargo, es necesario considerar:
- Definir correctamente las dependencias entre archivos  
- Contar con la herramienta `make` instalada  
- Ajustar los comandos según el compilador o lenguaje utilizado  

**Fuentes:**
- https://hernandis.me/blog/como-hacer-un-makefile/
- https://makefiletutorial.com/
- https://www.datacamp.com/es/tutorial/makefile-github-actions-tutorial

## 📌 Pregunta 3

El uso de tecnologías como Git y plataformas como GitHub permite gestionar versiones del código y facilitar el trabajo colaborativo. Git es un sistema de control de versiones distribuido que permite registrar cambios, revertir errores y trabajar en distintas versiones del proyecto.

Su utilidad incluye:
- Mantener un historial de cambios  
- Trabajar en paralelo sin sobrescribir código  
- Recuperar versiones anteriores  

En equipos de 3 o más personas, agrega valor porque:
- Permite trabajo simultáneo mediante ramas (*branches*)  
- Facilita la integración de cambios (*merge*)  
- Reduce conflictos si se utiliza correctamente  
- Mejora la organización del desarrollo  

Además, GitHub ofrece herramientas como revisión de código (*pull requests*), lo que contribuye a mejorar la calidad del software.

**Fuentes:**
-  https://docs.github.com/es/get-started/start-your-journey/about-github-and-git
- https://www.datacamp.com/es/blog/what-is-github
- https://docs.github.com/es/codespaces/developing-in-a-codespace/working-collaboratively-in-a-codespace

## 📌 Pregunta 4

Sí, es muy útil documentar las funciones implementadas en el código, ya que permite entender rápidamente qué hace cada parte del programa sin necesidad de analizar su implementación en detalle.

La documentación permite:
- Explicar el propósito de cada función  
- Describir parámetros y valores de retorno  
- Facilitar el mantenimiento del código  

No documentar el código puede generar problemas como:
- Dificultad para entender el funcionamiento  
- Mayor probabilidad de errores al modificarlo  
- Dependencia del autor original del código  

La documentación es especialmente importante en proyectos colaborativos o a largo plazo.

## 📌 Pregunta 5

La utilización de herramientas como `README`, `Makefile`, Git y GitHub es altamente relevante en el desarrollo de software, ya que cada una cumple un rol específico.

Estas herramientas se complementan de la siguiente manera:
- `README` → Explica el proyecto  
- `Makefile` → Automatiza la compilación  
- Git → Controla versiones  
- GitHub → Facilita la colaboración y distribución  

En conjunto, permiten:
- Mejor organización del proyecto  
- Mayor facilidad de uso para terceros  
- Desarrollo más ordenado y profesional  
- Mejor trabajo en equipo  

Estas tecnologías se integran de manera efectiva, logrando que el proyecto sea más claro, accesible y mantenible tanto para desarrolladores como para usuarios externos.
